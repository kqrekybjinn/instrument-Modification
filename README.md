# MODI 电机控制 HMI

ESP32-S3 + M0603A 总线电机，ESP-IDF v5.3，LVGL 8，480×320 横屏。

## 操作
- 自由模式：无目标圈数，显示相对本次起点的实际圈数。
- 定圈模式：目标 1–9999 整数圈，点击输入或用 ±1/±10 调整。
- 设定转速：50 / 100 / 200 / 300 / 380 RPM，直接选择；运行/暂停可平滑调速。
- GPIO12：启动 / 暂停 / 继续。GPIO15：停止。
- 暂停保留任务；停止结束当前运动，不自动反转。
- 完成/停止后选择新运行或回本次起点。新运行仅准备，按启动才读取新起点并运动。
- 回位点击即运动，使用当前设定速度并接近起点减速。途中停止保留起点，支持继续回位。
- 空闲/暂停不持续查询；运行时读取圈数，停止后读一次。不使用连续静止确认或反馈恢复门控。

## 显示
圈数是当前相对位移，保留两位小数，超调不被裁成目标值。回位时圈数向零下降。
显示的是设定 RPM。停止结果超出目标 ±0.5 圈时提示超差，不自动反向纠偏。

## 软件结构
- components/app/include/workflow.hpp：任务状态和操作许可。
- components/app/src/app_control_service.cpp：电机反馈、速度曲线、非阻塞减速、停止确认和命令执行。
- components/app/src/gui_app.cpp：实际 LVGL HMI、参数弹层及状态渲染。
- components/app/src/app_input_service.cpp：两个物理按键及稳定消抖。
- components/bsp/src/motor_driver.c：M0603A 10字节帧及 0x75 解析。

## 实机验收
先验证 0x75 反馈在正反向和跨圈时的连续关系，再测试目标 1/10/100 圈和任意起点、五档速度、暂停/继续、停止、回位中停止、反馈中断恢复。
停止误差允许 ±0.5 圈。位置跳变保护和失联自动停止已按用户要求删除。
已知未完成事项见 .planning/ISSUES.md。

正常采样采用角度跨零展开累计圈数，显示和定圈停止共用该值；里程仅辅助长间隔恢复。连续漏帧或暂停期间手动转轴超过半圈时，不能只靠单圈角度保证准确补圈。

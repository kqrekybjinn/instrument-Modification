# v1.0 软著材料整理说明

统一名称：MODI 总线电机控制与人机交互软件；统一版本：1.0。
现有使用说明书、软件设计说明书、版本记录及可追溯源码作为材料基础。
著作权人名称、开发完成日期和权属证明由申请人依据事实填写，仓库不代为作出声明。

依据国家版权局《计算机软件著作权登记办法》第十条，一般交存包括源程序和一种文档
前、后各连续 30 页，不足 60 页提交全部；除特定情况外程序每页不少于 50 行、文档每页不少于 30 行。
原文：https://www.ncac.gov.cn/xxfb/flfg/bmgz/202410/t20241015_869486.html

运行 `python3 tools/export_source.py` 可生成 dist/copyright/source-full.txt 和 source-manifest.csv。
工具按入口、应用、BSP 的固定顺序整理现有 C/C++ 业务源码，记录行数与 SHA-256；
排除第三方组件、测试桩和生成字体，不改写代码、不凑页数、不移除原有权利声明。
文本是排版输入，尚非已分页提交件；应据最终完整材料排版、标注统一名称版本及页码并核对连续性。
不足 60 页时提交全部，超过时从最终排版的完整材料提取前后各 30 页。
使用说明中的实际界面截图及申请人信息仍需在最终提交材料中补齐。

旧阶段计划、失效设计和调试过程说明已从发布树移除，保存在发布前外部备份及 Git 历史中。
原始协议说明、字体许可、回归测试及依赖锁文件保留。

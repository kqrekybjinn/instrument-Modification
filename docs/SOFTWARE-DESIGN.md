# MODI 总线电机控制与人机交互软件 v1.0 软件设计说明书

## 目标与结构

计数对象是 M0603A 电机轴，从任意任务起点运行指定圈数并显示实际相对位移。
采用速度模式，位置反馈参与计数、接近目标减速、终点判定和回位。
main/app_main.cpp 初始化 NVS 后启动 AppController；应用层以 C++ 服务组织，BSP 使用 C 驱动。

| 模块 | 职责 |
| --- | --- |
| app_controller.cpp | 服务装配、触摸命令桥接、存储状态刷新与启动读写检查 |
| app_control_service.cpp | 命令消费、反馈查询、任务起点、速度曲线与终点处理 |
| workflow.hpp | 任务状态与操作许可 |
| phase_position.hpp | 角度连续跟踪与里程相位对应关系学习 |
| position_math.hpp | 圈数、方向、位移换算 |
| gui_app.cpp / app_gui_service.cpp | LVGL 页面、参数输入、互斥与显示刷新 |
| app_input_service.cpp | GPIO 按键扫描与消抖 |
| app_usb_log_service.cpp | 快照采样、CSV 追加、写失败重试 |
| app_sensor_service.cpp | RS485 数据采集，目前数值解析为占位实现 |
| motor_driver.c | 10 字节协议帧、CRC、速度命令和位置反馈解析 |

## 状态与控制流程

自由/定圈是工作模式，准备、运行、暂停、完成、停止、回位等是任务状态。
触摸运动按钮按下立即入队，实体按键经消抖后使用相同控制命令。
控制服务统一处理任务状态，避免触摸与实体按键各自维护运动逻辑。
准备及新运行发送失能；启动依次使能、等待 100ms、设置速度模式、等待 20ms、读取新起点，再下发 30 RPM。
暂停与手动停止立即协议刹车，暂停保留任务；继续从 30 RPM 按约 120 RPM/s 平滑加速。
自动完成和回位终点保留接近目标减速逻辑，不等同于手动停止。

## 计圈设计

0x75 反馈包含整数里程和单圈角度，单圈用 32768 个单位表示。
实录显示里程变化边界和角度零位不完全重合，直接 mileage×32768+angle 会暂时多计一圈。
短间隔采用角度最短连续差值识别所在整圈分支，并学习里程与角度的相位对应关系。
长间隔根据已识别关系恢复整圈；边界区间无法确定时保留上次位置，不猜测整圈。
显示、定圈停止和回位共用修正后的位置，减去任务起点并应用运行方向得到相对圈数。
不硬编码某个初始角度，也不统一减去一圈。
位移上界根据采样期间实际已发送的速度峰值并留出余量计算；不能使用尚未达到的目标转速。
采样成功后更新峰值基准，失败则保留区间峰值，覆盖加速、减速与刹车阶段。
长时间失联或电机运行中重新上电可能无法保持可靠位置连续性。

## 并发与刷新

GUI 任务运行在 Core 1，控制、按键、传感器、日志和 USB 服务运行在 Core 0。
LVGL 使用递归互斥保护；控制侧渲染不等待 GUI 锁，繁忙时跳过本次显示更新。
准备约 200ms 查询位置，运行约 50ms 查询；查询耗时计入轮询周期。
暂停不持续轮询，停止后读取一次最终反馈；串口读取结果不构成持续安全确认门控。

## 数据与接口

电机接口 UART1、38400 bps、8N1，固定 10 字节帧，CRC-8/MAXIM；引脚见 bsp_pinmap.h。
立即刹车使用速度帧 DATA[7]=0xFF；准备释放使用失能命令，详细帧格式见 MOTOR-PROTOCOL.md。
USB 日志使用短文件名 logs/motor.csv 兼容当前 FAT 配置，约每 100ms 加 I/O 耗时采样，阶段变化也记录。
CSV 字段为 timestamp_ms、mode、motor_running、motor_rpm、sensor_value、target_count、
mileage_now、mileage_delta、rotation_units、feedback_valid、phase、angle_raw、
origin_mileage、origin_angle、origin_units。
仅空文件写表头；写入、刷新及同步错误返回上层，失败不推进成功标记，后续采样重试。

## 验证与维护

tests/run_host_tests.sh 覆盖计圈算术、相位跟踪、任务状态机、控制器、USB 写入故障与 LVGL 交互。
实录固定保存于 artifacts/diagnostics，作为回归输入保留，不随旧版说明清理。
第三方依赖由组件管理器及 dependencies.lock 管理，生成字体保留许可但不计入业务源码材料。
机械误差和实际负载下的表现按照使用说明进行硬件验收。

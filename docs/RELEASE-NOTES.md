# v1.0 版本记录

软件名称：MODI 总线电机控制与人机交互软件；版本：1.0；整理日期：2026-10-18。

## 发布内容

- 自由/定圈、正反方向、五档设定转速、暂停继续、新运行和回位。
- 立即手动刹车与平滑启动，自动终点减速。
- 里程/角度相位跟踪修正跨圈多计，按实际下发速度峰值处理高速启动反馈。
- 非阻塞 HMI 渲染和触摸/实体按键统一控制。
- USB 短文件名日志、追加写入、错误检查和失败重试。
- 统一版本、使用/设计说明、第三方许可和源程序整理工具。

## 软件验证

90 个历史反馈样本回放去除 6 次虚增整圈；高转速设定日志 4 次运行共 198 个样本回放通过。
控制器测试覆盖 96 组定圈与回位组合及 380 RPM 变采样间隔恢复。
按键/触摸、立即暂停停止、低速继续、USB 日志故障注入及实际 LVGL 交互测试通过。
ESP-IDF v5.3 固件编译通过。发布过程未烧录设备。

## 待验与边界

300/380 RPM 最新修复及各档速度、任意起点、双向停止误差 ±0.5 圈需实机复测。
失联自动停机未启用；无法确定的反馈保持上次计圈值。
传感器为占位解析，不宣称已实现物理量标定。
